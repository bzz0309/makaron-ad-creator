# Handoff

Repository: `https://github.com/bzz0309/makaron-ad-creator`

Start with `README.md`, then read `AGENT.md` and the master `skills/makaron-ad-creator/SKILL.md`.

The orchestration implementation is bundled inside the main Skill at `skills/makaron-ad-creator/scripts/makaron_ad_creator/`. Public distribution is the npm package `makaron-ad-creator-cli`, whose executable is `bin/makaron-ad.mjs`; `bin/makaron-ad` remains the source-tree fallback. The user-supplied v5 iOS workflow Skill and its UI/font assets live under `skills/edit-makaron-app-workflow-recording/`; the active master DAG runs that v5 synthetic renderer directly with the selected Marketplace Skill ID and mapped UI locale. Do not replace it with generic `screen-demo`.

Before live generation, run `npm test`, `npm run pack:check`, and `makaron-ad doctor`. A fresh Mac runs `npx -y makaron-ad-creator-cli setup` and `makaron-ad login` once; the verified key is stored in macOS Keychain and automatically reused by later user or Agent commands. `makaron-ad logout` removes it. A live campaign needs an owned/licensed image and exact Marketplace Skill metadata; the CLI automatically creates or reuses the one authorized persistent project bound to that Skill. Use `--locale en`, `--locale ja`, `--locale yue`, a comma-separated subset, or omit it for all three. The fixed UI mapping is `en→en`, `ja→ja`, `yue→zh-Hant`. Generate one target-Skill Effect, preferring Seedance 2.0, then derive non-overlapping Hook and Result ranges with the same Effect hash. Makaron chooses the best exact result frame for After and composes the comparison; bundled v5 creates each localized workflow and must pass its visual/technical QC. One campaign BGM is generated through `makaron music create`; each locale's complete Hook → comparison → workflow → Result → fixed Logo CTA ad is then exported by one project-bound Makaron chat through built-in `tiktok-video` Remotion with measured Seed Audio Caption JSON, Meta-safe subtitles, muted source/CTA audio, and the same BGM looped through the end. Final inputs are URL-first: reuse BGM/comparison source URLs, upload derived Hook/Result, v5 workflow and the bundled 207 KB three-second CTA excerpt once through `admin upload`, and never pass local video/audio paths through signed-URL PUT. Target 1080×1920, hard minimum 720×1280. Accept only authoritative generated images/videos. When final Makaron composition export returns 403, the CLI may locally encode the unchanged validated 15–20-second final-ad design. The complete CTA master and upload-safe excerpt are bundled under `skills/makaron-ad-creator/assets/`. Do not auto-publish completed ads.

Release steps are in `docs/releasing.md`; current open integration items are in `worklog.md`. Version `0.5.1` is the current published release; `0.6.0` is an unpublished candidate containing Seedance 2.0 routing, single-Effect Hook/Result derivation, restored v5 workflow generation, the 720p floor, Meta safe-zone, and scene-bound Remotion caption contract. No credentials are stored in this project.
