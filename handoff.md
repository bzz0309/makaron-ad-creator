# Handoff

Repository: `https://github.com/bzz0309/makaron-ad-creator`

Start with `README.md`, then read `AGENT.md` and the master `skills/makaron-ad-creator/SKILL.md`.

The orchestration implementation is bundled inside the main Skill at `skills/makaron-ad-creator/scripts/makaron_ad_creator/`. Public distribution is the npm package `makaron-ad-creator-cli`, whose executable is `bin/makaron-ad.mjs`; `bin/makaron-ad` remains the source-tree fallback. The user-supplied v5 iOS workflow Skill and its UI/font assets live under `skills/edit-makaron-app-workflow-recording/`; the active master DAG runs that v5 synthetic renderer directly with the selected Marketplace Skill ID and mapped UI locale. Do not replace it with generic `screen-demo`.

Before live generation, run `npm test`, `npm run pack:check`, and `makaron-ad doctor`. A fresh Mac runs `npx -y makaron-ad-creator-cli setup` and `makaron-ad login` once; the verified key is stored in macOS Keychain and automatically reused by later commands. `setup` falls back to a user-owned npm prefix on global-install `EACCES`; `makaron-ad logout` removes the stored key. A live campaign needs an owned/licensed image and exact Marketplace Skill metadata. Registry v2 creates or reuses a project generation for the exact `(Skill ID, input SHA-256)` pair, isolates a changed image, and rotates only at the guarded media-capacity threshold while keeping history; matching legacy bindings migrate automatically. Use one selected locale or omit it for all three. Generate one target-Skill Effect, derive non-overlapping Hook and Result ranges with the same Effect hash, select the best exact After frame, and render the locale-correct v5 workflow. The comparison is a local deterministic node: fixed 1080×1920 black canvas, shared `common_h`, complete aspect-preserved images, exactly 10px between the actual image boxes, at least 40px symmetric outer margins, labels centered under the actual images 35px below their edge on one baseline, and pixel-level QC. It must never be delegated to Makaron or another Agent. Each final uses measured Seed Audio Caption JSON, ratio-based Meta-safe centered subtitles without manual newlines, muted source/CTA audio, and the same campaign BGM through CTA. Final inputs are URL-first: reuse authoritative 1080p source URLs and normalize local/lower-resolution Hook, Result, workflow, and CTA transport copies to 1080×1920 with adaptive CRF before cached `admin upload`. If cloud materialization fails after returning a complete design, preserve the failed stdout, rebind current assets, and render that exact contract-v2 design through the pinned local Remotion runtime with `Loop` support. `status/run` accept campaign ID, directory, or config path, and recover orphaned RUNNING nodes without repeating passed work. The hard delivery floor remains 720×1280. Do not auto-publish completed ads.
